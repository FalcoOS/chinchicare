# ChinchiCare v2.0

Responsive zweisprachige PWA für Chinchilla-Halter.

## Funktionen
- Mehrere Tierprofile mit Foto, Alter, Geschlecht, Farbe und Notizen
- Gewichtstagebuch mit einfacher Verlaufskurve
- Raumklima-Check: Temperaturregler, Luftfeuchtigkeit, Hinweise und Messprotokoll
- Pflege-Checkliste und eigene Aufgaben
- Wissensbereich
- Datenexport und Import als JSON-Backup
- Deutsch/Englisch, mobile iPhone/iPad-Ansicht

## GitHub Pages
Lade alle Dateien aus diesem Ordner in den Stamm deines Repositorys hoch. Danach unter **Settings → Pages** die Quelle **Deploy from a branch**, Branch `main` und Ordner `/ (root)` auswählen und speichern.

## Als App verwenden
In Safari die veröffentlichte Seite öffnen, Teilen → Zum Home-Bildschirm. Das ist eine Web-App/PWA, keine native App aus dem App Store.

## Hinweise
Temperatur wird nicht automatisch gemessen. Bitte am Thermometer ablesen. Angaben bleiben lokal in diesem Browser und werden nicht automatisch synchronisiert. Exportiere regelmäßig ein Backup. Klima-Hinweise sind allgemeine Orientierung und kein Ersatz für tierärztlichen Rat.
