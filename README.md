# ChinchiCare für iPhone testen

Dieses Paket ist eine installierbare Web-App (PWA). Du brauchst keinen Mac und musst noch kein Apple-Developer-Konto bezahlen.

## Kostenloser Weg über GitHub Pages
1. Öffne auf deinem Windows-PC https://github.com/ und melde dich an oder erstelle ein kostenloses Konto.
2. Erstelle ein neues Repository mit dem Namen `chinchicare`, stelle es auf **Public** und erstelle es ohne README/weitere Dateien.
3. Entpacke dieses ZIP auf deinem PC.
4. Öffne das Repository auf GitHub und wähle **Add file → Upload files**.
5. Lade alle fünf Dateien/Dateitypen aus diesem Ordner hoch: `index.html`, `manifest.webmanifest`, `service-worker.js`, `icon-192.png`, `icon-512.png`. `README.md` kannst du ebenfalls hochladen.
6. Klicke auf **Commit changes**.
7. Öffne im Repository **Settings → Pages**. Bei **Build and deployment** wähle **Deploy from a branch**, Branch `main`, Ordner `/(root)`, dann **Save**.
8. Warte, bis GitHub Pages veröffentlicht hat. Die Adresse lautet normalerweise `https://DEIN-BENUTZERNAME.github.io/chinchicare/`.
9. Öffne diese HTTPS-Adresse in Safari auf dem iPhone.
10. Tippe auf **Teilen** → **Zum Home-Bildschirm** → **Hinzufügen**. Starte ChinchiCare danach über das neue Symbol.

## Was du testen kannst
- Tierprofile anlegen und löschen
- Gewichtseinträge dokumentieren
- Pflegeaufgaben hinzufügen, abhaken und löschen
- Futterlexikon durchsuchen
- Käfigmaße und Sicherheitscheckliste verwalten

## Daten und Grenzen
- Die Daten werden im Browser lokal auf dem jeweiligen Gerät gespeichert. Sie werden NICHT zwischen iPhone und PC synchronisiert.
- Lösche nicht die Website-Daten in Safari, wenn du gespeicherte Einträge behalten möchtest.
- Für Community, Nutzerkonten, Cloud-Synchronisierung und echte Push-Erinnerungen wäre weitere Entwicklung nötig.
- Inhalte im Futterlexikon und Ratgeber sind ein Prototyp und müssen vor öffentlicher Nutzung fachlich geprüft werden.
- GitHub Pages ist ein kostenloser Hosting-Weg für dieses Testprojekt; das Repository ist öffentlich. Lade deshalb keine privaten Daten oder echten persönlichen Informationen hoch.
