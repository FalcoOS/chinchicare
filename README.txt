ChinchiCare Cartoon Edition\n\nDateien: index.html, style.css, app.js\n\nDiese Version zeigt beim Öffnen ausdrücklich eine Anmeldemaske mit Anmelden, Konto erstellen und Gastmodus. Funktionen: Chinchilla-Profile, Fotos bis 2 MB, Gewichtstagebuch mit Diagramm, Klima-Check, Pflegeplan, Cartoon-Design, responsive iPhone-Oberfläche.\n\nInstallation: Sichere zuerst die alte Version. Ersetze index.html, style.css und app.js im Repository https://github.com/FalcoOS/chinchicare mit diesen Dateien. Commit changes und warte auf GitHub Pages.\n\nSupabase Cloud-Sync setzt aktivierte Email Auth, die vorhandene public.app_state Tabelle und eine RLS-Policy mit auth.uid() = user_id voraus. Ohne Anmeldung speichert die App lokal im Browser. Die Fotos werden lokal als Data URL gespeichert und können bei vielen/großen Fotos viel Speicher belegen.\n\nDas ist ein Prototyp. Die Klima-Einschätzung ersetzt keine tierärztliche Beratung. Niemals service_role/secret keys in Frontend-Code einfügen. Vor dem Austausch alte Dateien sichern.
