ChinchiCare – Care Planner Expansion

Files: index.html, app.js, style.css, manifest.webmanifest.

Features added:
- Custom weekly care tasks with weekday selection, check-off, deletion and local-device persistence.
- Enclosure size calculator using internal length, depth, height and animal count. Shows floor area, volume, floor area per animal and a cautious rule-of-thumb assessment.
- Phone camera preview to help frame the enclosure. IMPORTANT: the camera preview does not measure dimensions automatically. It is not true AR measurement. A compatible AR measuring app/device would be required for that.
- Expanded care articles on fur care, skin/fur warning signs and safe cage accessories.
- Chinchilla species and coat-colour guide. Colour examples are stylised visuals, not real animal photographs. Species information distinguishes wild species from domesticated colour varieties.

Installation:
1. Replace the existing project files with these files in the GitHub Pages repository.
2. Commit the changes and wait for deployment.
3. Test custom tasks, language changes, calculator and camera permission on the target device.

Data is saved locally in the browser. This build has syntax and basic HTML parsing checks, but has not been live-tested against the deployed site, Supabase, or all mobile browsers.

Animal welfare note: enclosure output is only a rough planning aid, not a legal minimum or veterinary recommendation. Verify current local guidance with a reputable chinchilla welfare organization or an experienced exotic-pet veterinarian. The species cards use stylised visuals, not real photographs.
